# Review
Independently inspect locked task, rules, diff/source, and test/CI evidence. Check scope, correctness, auth/privacy, replay/idempotency, framework compatibility, DB/performance, payment state transitions, and meaningful tests. Return APPROVE, REJECT, or NEEDS_HUMAN with evidence.
